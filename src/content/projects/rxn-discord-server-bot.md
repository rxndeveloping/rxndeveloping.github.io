Our bot is a comprehensive moderation and community management tool built for our Assetto Corsa Discord Server. Developed in JavaScript with discord.js, the bot handles automated welcome messages, multi-category ticket systems with HTML transcripts, reaction-based giveaways with timer and reroll functionality, staff-only event creation modals, server information panels, role assignment, and channel cleanup commands. It integrates deeply with Discord's API using slash commands, modals, buttons, and embeds to provide a polished user experience for both members and staff.
