This is a personal Unity project created to design and implement the core systems of a first-person shooter experience. The development focused on building a custom first-person controller featuring responsive movement, acceleration, deceleration, air control, jumping, bunny hopping, crouching, slow walking, and weapon-dependent mobility.

The project includes a weapon system with automatic fire, hitscan shooting, ammunition management, reloading, weapon inspection, recoil patterns, movement-based spread, visual recoil, weapon sway, hit markers, impact effects, and sound feedback. It also features a rifle-and-knife switching system, viewmodel animations, knife-specific mobility, stamina mechanics, and jump-charge mechanics.

The interface includes HUD elements for health, stamina, ammunition, weapon state, crosshair, and damage feedback. The project also contains a main menu, pause menu, settings menu, confirmation dialogs, cursor management, and UI flow systems for navigating different gameplay and menu states.
